DWFx Measure: user guide

3D model take-off in Excel, for quantity surveyors

DWFx Measure opens Revit DWFx models (architecture, structure, interiors, MEP) inside Excel. You select elements in a 3D view or an element browser, measure them, and the add-in writes the take-off to your workbook with live formulas. Projects, models, drawings and take-offs are saved on the server for your team.

1. Install the add-in

You need Microsoft 365 Excel (Windows, Mac or Excel on the web). Choose one way:

Your IT team deploys it (best for companies)

IT uploads manifest.xml once in the Microsoft 365 admin center (Settings › Integrated apps › Upload custom apps). The add-in then appears for the chosen users without any setup.

A shared folder (Excel for Windows)

  1. Put manifest.xml in a shared network folder, for example \\PC-NAME\AddIns.
  2. In Excel: File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs. Add the folder path, tick Show in Menu, press OK.
  3. Restart Excel. Home › Add-ins › More add-ins › Shared Folder › DWFx Measure › Add.

Excel on the web

Home › Add-ins › More add-ins › My Add-ins › Upload My Add-in, then choose manifest.xml.

After adding it, Excel shows a DWFx Measure tab on the ribbon.

The tab does not show, or shows old buttons? In Trusted Add-in Catalogs, tick Next time Office starts, clear all previously-started web add-ins cache, restart Excel, and add the add-in again.

2. Sign in

  1. Press DWFx Measure › Projects on the ribbon. The task pane opens on the right.
  2. Type the email and password your administrator gave you, then Sign in. You stay signed in on this computer for 30 days.
  3. To sign out or change the colour theme, press your initials at the top right.
After 8 wrong passwords the account is locked for 15 minutes. If you forgot your password, ask your administrator for a new one.

3. Projects and models

  1. New project: give it a name, and a code and client if you like.
  2. Upload DWFx: choose the file exported from Revit and a model name such as Structure or Architecture. Uploading again with the same model name creates version 2, 3 and so on.
  3. Wait until the version shows Ready (large models take a minute; you can keep working), then press Open.
  4. Drawings and documents: upload PDFs and images; press View to open them. 2D sheets inside a DWFx appear as 2D sheets on the version.
  5. Team: add colleagues as Viewer (open and download), Editor (also upload and measure) or Owner (also manage the team, settings and delete).
  6. Project settings (owners): switch the AI off for confidential work, set the opening size that is not deducted (default 0.5 m²), and describe your BOQ house style.

5. Selecting elements and zones

  • Elements tab: Category › Family › Type › element. Tick any level of the tree. Search by type, family or Revit ID; filter by level.
  • Isolate shows only the selection, Hide hides it, Show all brings everything back. Ctrl+Z / Ctrl+Y undo and redo.
  • Zones (bottom of the Elements tab): select elements (box select on a level plan works well), type a name such as Villa A, press Create from selection. Zones can colour the model and split take-offs (sub-totals by zone).
  • Select rows in the Take-off sheet and the elements light up in 3D (or press Select from Excel on the ribbon).

6. Measuring

  1. Select the elements, then open the Measure tab.
  2. Tick the quantities you need. The Source column says where each number comes from: Revit (exported values), geometry (measured exactly from the 3D faces), type name (sizes like 200X750) or doors/windows (openings in walls).
  3. Optional: add formula columns using the {keys}, for example {Geo_bottom_area} + {Geo_side_area} for beam formwork.
  4. Choose sub-totals (type, level, zone, category) and press Add to Excel take-off. The group (G1, G2…) is written to the Take-off sheet with live formulas and saved to the project.

Templates and discipline packs (bottom of the Measure tab) hold ready methods for Structure, Architecture, Interiors and MEP, plus methods you save with Save as template. Apply finds the matching elements and previews the totals.

In Excel, yellow cells are assumptions (for example slab thickness). Change them and every row recalculates. Green column headers are formula columns.
One table for the same elements. When you add concrete, formwork, reinforcement, waterproofing… for exactly the same elements (from the Measure tab, a template, the AI or a dimension group), the add-in adds the new columns to the table that already holds those elements instead of starting a new table. Different element sets still get their own tables.

7. 3D window: project tree and dimension groups

Press 3D window (ribbon or 3D toolbar). The window is a full measuring workspace: the project tree on the left, the model in the middle, drawings and properties on the right (Drawings and properties button). Drag the grey bars to resize.

Drawings, Model and Views tabs (top left)

  • Drawings: your folders, 3D models (with their versions and DWFx sheets) and drawings. Right-click for New Folder, Rename Folder, Delete Folder (the contents move up, nothing is lost) and Upload Drawings Here. Move a model or drawing with Change Folder… or drag it onto a folder. Double-click a version to open it (the task pane follows); double-click a drawing to see it on the right.
  • Model: Category › Family › Type with the number of objects. Click to select; right-click for Show Only, Hide, Import and Create Dimension Group.
  • Views: the team's saved views.

Click a schedule row to isolate it in 3D

Every schedule row keeps the Revit ID of its element, so the sheet and the 3D model stay linked both ways.

  1. Click a row number in a schedule (or drag over several row numbers). The elements of those rows are selected in 3D and the view moves to them.
  2. Click the group row (G1, G2 …) to select every element of that schedule.
  3. Press Isolate in the 3D toolbar to show only the selection. Show all brings the rest back.

8. AI assistant

  1. Open the AI tab and describe what to measure, for example "Formwork to beams on Level 1, soffit and sides less a 200 mm slab", or pick a common request.
  2. The AI searches the model, reads the real quantities, tests its formulas and checks your QS rules. Open How the AI worked it out to see its steps.
  3. Check the method and assumptions, change them if needed, then Add to Excel. Save as template keeps a good method for the team.

The AI chooses the method; the add-in calculates every number from the model. The AI receives element names, counts, levels and quantity names, never the file or the 3D geometry. It can be switched off per project.

9. Checks (Review tab)

  • Missing data: elements without 3D, without a level, concrete without a volume, beams without a size in the type name.
  • Measured status: green measured once, purple measured twice or more (possible double count), red not measured.
  • Overlapping concrete: duplicates or elements that would be counted twice.
  • AI take-off check: a review for missing items, odd values, unit mistakes and double counting.

10. Revisions

  1. Upload the new DWFx with the same model name, so it becomes the next version, and open it.
  2. Review › Revisions › Compare: added, removed and changed elements, and the quantity differences. Colour the model by changes shows them in 3D.
  3. Update selected groups re-measures your take-off on the new version by Revit ID. Formulas and your assumption values stay; groups made from a template or the AI also pick up new elements. A Change log sheet records the before and after totals.

11. BOQ and audit PDF

  • Build BOQ sheet: choose the totals that become BOQ items (final results are ticked by default to avoid double counting). Quantities link to the take-off totals, so the BOQ updates with them. Rates you type are kept when you rebuild. Tick the AI option for item descriptions in your house style.
  • Create audit PDF: method, assumptions, element counts, totals and a 3D picture for every group, saved to the project.
  • Project › Saved take-off groups › Restore rebuilds the Take-off sheet in any workbook.

12. Your first take-off, step by step

  1. Ribbon DWFx Measure › Projects, sign in.
  2. New project › name › Create project.
  3. Upload DWFx › choose the file › model name Structure › Upload and process. Wait for Ready, press Open.
  4. Measure tab › Templates and discipline packs › Concrete to beams › Apply › Add to Excel.
  5. Check the new Take-off sheet: group G1 with one row per beam and the totals.
  6. Review › Output › Build BOQ sheet. Type a rate in a yellow cell to see the amount.

13. For administrators

  • Users are lines in the Railway variable APP_USERS: email | full name | role | password hash (role is admin or user). Make the hash in Admin › Create a password hash. Changing a password or removing a line signs that user out everywhere.
  • AI assistant: choose the provider and model, the daily limit per user, and run the 50-request QS test set after any change (target 45 of 50).
  • Company QS rules: your measurement conventions; the AI reads them for every request.
  • Errors: errors from the server and the add-in, with the reference number users see.
  • Backups: the database is backed up every day (last 30 kept); Back up database now makes one immediately. Export ZIP on a project downloads all its files.

14. Problems and answers

ProblemWhat to do
The ribbon tab is missing or shows old buttonsClear the web add-ins cache (see Install), restart Excel, add the add-in again. The ribbon needs Microsoft 365 Excel.
"Too many sign-in attempts"Wait 15 minutes, or ask your administrator for a new password.
A version shows FailedPress Try again. If it fails again, publish the DWFx from Revit with element properties included, and tell your administrator.
An old version has no exact quantities or opens slowlyIt was processed before the update: press Try again on the version to reprocess it.
An error message shows a referenceSend the reference (for example A1B2C3D4) to your administrator; it identifies the error in Admin › Errors.
Some elements are not in 3DTheir geometry is not in the DWFx; they can still be measured from their properties (Review › Missing data lists them).
Geo volume is missing for an elementThe element is not a closed solid in the export. Use the Revit Volume for it.

Your data: projects, files and take-offs are stored on the company's Railway server (EU region) and are only visible to the project team. Deleting a project removes its files from the server.
