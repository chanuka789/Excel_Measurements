DWFx Measure: user guide

3D model take-off in Excel, for quantity surveyors

DWFx Measure opens Revit DWFx models (architecture, structure, interiors, MEP) inside Excel. You select elements in a 3D view or an element browser, measure them, and the add-in writes the take-off to your workbook with live formulas. Projects, models, drawings and take-offs are saved on the server for your team.

1. Install the add-in

You need Microsoft 365 Excel (Windows, Mac or Excel on the web). Choose one way:

Your IT team deploys it (best for companies)

IT uploads manifest.xml once in the Microsoft 365 admin center (Settings › Integrated apps › Upload custom apps). The add-in then appears for the chosen users without any setup.

A shared folder (Excel for Windows)

  1. Put manifest.xml in a shared network folder, for example \\PC-NAME\AddIns.
  2. In Excel: File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs. Add the folder path, tick Show in Menu, press OK.
  3. Restart Excel. Home › Add-ins › More add-ins › Shared Folder › DWFx Measure › Add.

Excel on the web

Home › Add-ins › More add-ins › My Add-ins › Upload My Add-in, then choose manifest.xml.

After adding it, Excel shows a DWFx Measure tab on the ribbon.

The tab does not show, or shows old buttons? In Trusted Add-in Catalogs, tick Next time Office starts, clear all previously-started web add-ins cache, restart Excel, and add the add-in again.

2. Sign in

  1. Press DWFx Measure › Projects on the ribbon. The task pane opens on the right.
  2. Type the email and password your administrator gave you, then Sign in. You stay signed in on this computer for 30 days.
  3. To sign out or change the colour theme, press your initials at the top right.
After 8 wrong passwords the account is locked for 15 minutes. If you forgot your password, ask your administrator for a new one.

3. Projects and models

  1. New project: give it a name, and a code and client if you like.
  2. Add DWFx: choose the file exported from Revit and a model name such as Structure or Architecture. Adding again with the same model name creates version 2, 3 and so on.
  3. The model is processed on this computer. Wait until the version shows Ready (large models take a minute; keep the add-in open), then press Measure (measurement window) or Schedules (DWFx Schedules window).
  4. Drawings and documents: add PDFs, images, DWG and DXF; press Open & measure. 2D sheets inside a DWFx appear as 2D sheets on the version.
  5. Team: add colleagues as Viewer (open), Editor (also add files and measure) or Owner (also manage the team, settings and delete).
  6. Project settings (owners): switch the AI off for confidential work, set the opening size that is not deducted (default 0.5 m²), and describe your BOQ house style.

5. Selecting elements and zones

  • Elements tab (DWFx Schedules window): Category › Family › Type › element. Tick any level of the tree. Search by type, family or Revit ID; filter by level.
  • Isolate shows only the selection, Hide hides it, Show all brings everything back. Ctrl+Z / Ctrl+Y undo and redo.
  • Zones (bottom of the Elements tab, DWFx Schedules window): select elements (box select on a level plan works well), type a name such as Villa A, press Create from selection. Zones can colour the model and split take-offs (sub-totals by zone).
  • Select rows in the Take-off sheet and the elements light up in 3D (or press Select from Excel on the ribbon).

6. Measuring

  1. Select the elements, then open the Schedule tab of the DWFx Schedules window.
  2. Tick the quantities you need. The Source column says where each number comes from: Revit (exported values), geometry (measured exactly from the 3D faces), type name (sizes like 200X750) or doors/windows (openings in walls).
  3. Optional: add formula columns using the {keys}, for example {Geo_bottom_area} + {Geo_side_area} for beam formwork.
  4. Choose sub-totals (type, level, zone, category) and press Export schedule to Excel. The group (G1, G2…) is written to the Take-off sheet with live formulas and saved to the project.

Templates and discipline packs (bottom of the Schedule tab) hold ready methods for Structure, Architecture, Interiors and MEP, plus methods you save with Save as template. Apply finds the matching elements and previews the totals.

In Excel, yellow cells are assumptions (for example slab thickness). Change them and every row recalculates. Green column headers are formula columns.
One table for the same elements. When you add concrete, formwork, reinforcement, waterproofing… for exactly the same elements (from the Measure tab, a template, the AI or a dimension group), the add-in adds the new columns to the table that already holds those elements instead of starting a new table. Different element sets still get their own tables.

7. measurement window: project tree and dimension groups

Press measurement window (ribbon or 3D toolbar). The window is a full measuring workspace: the project tree on the left, the model in the middle, drawings and properties on the right (Drawings and properties button). Drag the grey bars to resize.

Drawings, Model and Views tabs (top left)

  • Drawings: your folders, 3D models (with their versions and DWFx sheets) and drawings. Right-click for New Folder, Rename Folder, Delete Folder (the contents move up, nothing is lost) and Add Drawings Here. Move a model or drawing with Change Folder… or drag it onto a folder. Double-click a version to open it (the task pane follows); double-click a drawing to see it on the right.
  • Model: Category › Family › Type with the number of objects. Click to select; right-click for Show Only, Hide, Import and Create Dimension Group.
  • Views: the team's saved views.

Right-click an object in 3D

Click a schedule row to isolate it in 3D

Every schedule row keeps the Revit ID of its element, so the sheet and the 3D model stay linked both ways.

  1. Click a row number in a schedule (or drag over several row numbers). The elements of those rows are selected in 3D and the view moves to them.
  2. Click the group row (G1, G2 …) to select every element of that schedule.
  3. Press Isolate in the 3D toolbar to show only the selection. Show all brings the rest back.

8. On-screen take-off on drawings and in 3D

Measure by clicking on a drawing or on the 3D model, the same way as in CostX. Every measurement goes into a dimension group, keeps its points (so you can see it again on the drawing), and goes to Excel with the group's schedule.

Your files stay on your computer

Drawings and models are kept on this computer (in the add-in's own storage) and processed here, with this computer's power. The project on the server keeps only each file's name, size and fingerprint, and your measurements. Each file shows On this computer or Not on this computer yet.

  • Teammates: send them the file (email, shared drive). When they open it, the add-in asks them to choose it and checks that it is the same file. Or they add it under On this computer › Add files you received.
  • On this computer (project page) lists what is kept here and the space used. Clear processed frees space (the model is made again when you open it); Remove takes the file off this computer only.
  • Files added before are still on the server and open as before. An owner can press Keep on computers only to move one here and delete the server copy (send the file to the team first).

Open a drawing to measure

  1. Add PDFs or images in Project & Models > Drawings and documents. 2D sheets inside a DWFx can be measured too.
  2. Press Open & measure (task pane), or double-click the drawing in the measurement window's Drawings tree. In the measurement window the drawing opens in a tab next to 3D model.
  3. Set the Scale of the page: choose 1:50, 1:100 … (PDFs and DWFx sheets), or choose Calibrate…, click the two ends of a length you know and type it in metres. Images always need calibration. Changing the scale recalculates every dimension already on the page.

Measure

  1. Choose the current dimension group in the list at the top left, or press + Group (name, Area / Length / Count, optional height, colour).
  2. Press Measure. The group's type decides what you measure:
    • Area: click each corner; finish with Enter, a double-click or a right-click. Shift + two clicks measures a rectangle. The perimeter is kept too.
    • Length: click along the line, finish the same way.
    • Count: click each item.
  3. Positive / Negative: negative dimensions are deductions (openings, voids). They are hatched and subtract from the group total.
  4. The cursor snaps to drawing line ends (yellow square) and onto lines (yellow cross) and to the corners of other dimensions. Hold B to stop snapping. A turns angle snap (15° steps) on or off. Backspace removes the last point, Esc cancels, M measures a distance without saving it.
  5. Navigate: mouse wheel zooms at the cursor, drag (or middle button, or Space + drag) pans, Extents fits the page, View > Rotate turns the view.

Change dimensions

  • Click a dimension to select it (Ctrl+click adds, Shift+drag selects an area, Ctrl+A selects all). Hover to see its name, group and quantities.
  • Drag a selected dimension to move it, or drag one of its corner handles. Right-click for: Edit Dimension Properties, Move to Another Dimension Group, Change Multiplier, Make Negative / Positive, Rotate 90°, Mirror, Copy, Delete.
  • Copy and paste (Ctrl+C, Ctrl+V) puts dimensions in the same place on another page or drawing, for example from Level 1 to Level 2.
  • View > Drawing Properties: the drawing multiplier repeats every dimension on the drawing (for example 10 for a typical floor used ten times). Effective multiplier = dimension multiplier × drawing multiplier.
  • View also has Labels, Legend, Markups, Monochrome, Layers (PDFs with layers), Show every group or only the current one, and Picture.
  • Markups: right-click the drawing > Create Markup. Drag the text or its pointer to move them; right-click to edit or delete.

Measure in 3D (point mode)

  1. In the 3D toolbar press Measure. Under Take-off into a dimension group, choose the current group (or + Group) and tick Negative if needed.
  2. Measure by points: click corners on the model for an area, points along it for a length, or items for a count. Enter, double-click or right-click finishes. Shift-click a face to take its whole area.
  3. Face area: one click takes the whole flat face of an element (for example a slab soffit or a wall face).
  4. The dimensions are drawn on the model in the group's colour. In the measurement window, click a dimension in the Dimensions tab to show it on its drawing or in 3D.

Auto Count

  1. Make a Count group current, then press Auto Count.
  2. Press Capture and drag a box tightly around one symbol (a door, a light fitting). Set a working area or hide layers first to search only part of the drawing.
  3. Press Search. Copies are found even when they are rotated or mirrored. Show matches above hides weak matches; Auto accept above accepts the close ones.
  4. Yellow = to check, green = accepted, red = rejected. Click yellow once to accept or twice to reject; click green to reject; click red to accept. Shift-click a symbol it missed to add it.
  5. Press Save accepted: each one becomes a count dimension. The captured symbol stays, so you can search other drawings with it.

Cutouts

  1. Measure the large area as a positive dimension and the void or opening as a negative dimension.
  2. Select the negative dimension (and the positive one too if several are stacked), right-click > Convert to Cutout.
  3. The negative dimension becomes a hole in the positive one (or a notch, or the positive one is split into two dimensions). Area and perimeter are recalculated.
  4. To take a hole away, right-click inside it > Remove Cutout (the negative dimension is not restored).

Rebar mode

  1. Make a Length group current and press Rebar.
  2. Click the two ends of the spacing line (the distance the bars cover), then the two ends of one bar.
  3. Enter the spacing and any extra length per bar (laps, hooks). Bars = distance ÷ spacing + 1; total = bars × (bar length + extra). The covered bars are drawn faintly.

Compare two drawings

  1. View > Compare with Another Drawing, choose the drawing and page.
  2. This drawing shows in green, the other in red; lines in both look dark, so changes stand out. Use the sliders to fade either one.
  3. Press Align and drag to line them up. You can measure while comparing: dimensions are saved on this drawing.

Working area

View > Set Working Area, then drag a box: only that part of the drawing is shown, snapped to and searched by Auto Count, and Extents zooms to it. Use it for one unit on a typical floor plan, or a detail at another scale. Reset Working Area shows the whole page.

DWG and DXF drawings

Add DWG or DXF files like any drawing and press Open & measure. DXF files are read on this computer. DWG files are read by the server for that moment only and nothing is kept there (this can take a minute the first time; the result is then kept on this computer). CAD drawings are measured 1:1 in the file's own units, so no scale or calibration is needed; check one known length with Distance. View > Layers shows or hides CAD layers, and the cursor snaps only to visible layers. If a DWG cannot be read (some older versions), save it as DWG 2013-2018, DXF or PDF and add it again.

9. AI assistant

  1. Open the AI tab of the DWFx Schedules window and describe what to measure, for example "Formwork to beams on Level 1, soffit and sides less a 200 mm slab", or pick a common request.
  2. The AI searches the model, reads the real quantities, tests its formulas and tests the schedule on the elements. Open How the AI worked it out to see its steps.
  3. Check the method and assumptions, change them if needed, then Add to Excel. Save as template keeps a good method for the team.

The AI chooses the method; the add-in calculates every number from the model. The AI receives element names, counts, levels and quantity names, never the file or the 3D geometry. It can be switched off per project.

10. Live links between Excel and the measurements

  1. Select a cell in Excel.
  2. In the measurement window (or the task pane list), drag a dimension group or a dimension onto the blue bar Drop here to link to the selected Excel cell, double-click it, or press Link to Cell. Excel does not let an add-in drop straight into a cell, so the bar is the drop target.
  3. The cell gets a live formula, for example =CX.QTY("1a2b3c4d") for the group total or =CX.VALUE("1a2b3c4d","9f8e7d6c") for one dimension. It changes as soon as you measure. You can use it inside your own formulas: =CX.QTY("1a2b3c4d")*1.05.
  4. Follow Excel on: click a linked cell and the measurement window opens the drawing (or the 3D model) and highlights where it was measured. Select a group or a dimension and its linked cells are selected in Excel. Switch Follow Excel off when you do not want the window to jump; the links always stay.
  5. Workbook View (tab in the measurement window) lists every linked cell with Go to cell, Show and Remove link (the cell keeps its last value).

Sending the workbook to someone without the add-in

  1. Press Share Copy (ribbon or task pane). Every linked cell becomes a plain number; your other formulas stay. The live formulas are kept inside the workbook.
  2. File › Save a Copy, and send that copy. Everyone can see the numbers, with or without the add-in.
  3. Press Restore Links: your links are live again. A cell someone typed over is left as it is.
After updating to version 0.7, add the new manifest.xml to Excel again (remove the old add-in first). Without it, the CX formulas show #NAME?.

11. DWFx Schedules window

  1. Ribbon DWFx Schedules (or Schedules on a model version in Projects). Choose the model version at the top right.
  2. Select elements in the Elements tab or in 3D.
  3. Schedule tab: tick the data columns (category, family, type, level, mark, zone) and the quantities the elements have.
  4. Add calculated columns to the same table: Formwork (all faces), Reinforcement (volume × rate; the rate is a yellow cell you can change), tonnes, or your own formula.
  5. Export schedule to Excel. Clicking a row on the Take-off sheet highlights its elements in the Schedules window. Summary sheets build totals by level or zone with formulas.
  6. Or ask the AI: "Schedule all beams by level with volume, formwork and reinforcement". You see the schedule first; nothing is written until you press Run or Export.

12. The same file on more than one computer (paths)

  • Files stay on the computers. When a computer does not have a drawing or model yet, the add-in looks in the places this computer remembers, then shows the saved paths of every computer.
  • Press Choose the file… or Choose a folder… (a local folder, or a SharePoint / OneDrive library synced to the computer). The fingerprint is checked and the path is saved for this computer. Older paths are kept, so going back to a previous computer works again.
  • SharePoint links can be saved too; Open link opens them in the browser to download or sync the file. Syncing the SharePoint library with OneDrive is the easiest setup.
  • Drawing Manager › Paths lists, adds and removes the paths of a drawing.

13. Your first measurement, step by step

  1. Ribbon DWFx Measure › Projects, sign in, New project.
  2. Add a PDF drawing in Drawings and documents, then press Open & measure: the measurement window opens.
  3. Set the scale (Drawings › Scale, or Calibrate). Dimensions › Add a dimension group, for example Floor tiles (Area).
  4. Click the corners of a room and press Enter. The group total updates in the task pane.
  5. Select a cell in Excel and double-click the group: the cell shows =CX.QTY(...) and follows every change.

14. For administrators

  • Users are lines in the Railway variable APP_USERS: email | full name | role | password hash (role is admin or user). Make the hash in Admin › Create a password hash. Changing a password or removing a line signs that user out everywhere.
  • AI assistant: choose the provider and model, the daily limit per user, and run the 50-request QS test set after any change (target 45 of 50).
  • Company QS rules: your measurement conventions; the AI reads them for every request.
  • Errors: errors from the server and the add-in, with the reference number users see.
  • Backups: the database is backed up every day (last 30 kept); Back up database now makes one immediately. Export ZIP on a project downloads all its files.
